# Remoplus landing page

Static HTML/CSS/JS translation of the Figma design (and its Framer site). Open `index.html` in a browser — no build step.

- `index.html` – markup for all sections (header, hero, features, testimonials, demo, pricing, integrations, security, blog, CTA, footer)
- `styles.css` – design tokens (dark `#0e0f0c`, lime `#baff38`, Outfit font) and responsive layout
- `script.js` – mobile menu, testimonial slider, monthly/yearly pricing toggle, count-up, scroll reveal

Photos (avatars, blog images, partner logos) are CSS placeholders; swap in real assets exported from Figma.
